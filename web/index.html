Filename patterns we can read

  • SDRSharp_YYYYMMDD_HHMMSSZ_<freq>Hz_IQ.wav
  • HDSDR_YYYYMMDD_HHMMSSZ_<khz>kHz_RF.wav
  • *_<rate>sps_*
  • *_fc<freq>_*
  • .cs8 / .cs16 / .cf32 extensions

A stereo WAV is read as I/Q. A mono WAV is treated as real audio. A headerless file has its sample format guessed from the histogram, and if no sample rate can be found anywhere, frequencies are reported as a fraction of the sample rate rather than as invented Hz.
